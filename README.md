# Flights-Analytics
## Overview
The Flight Analytics Project is a data visualization and analytics web application built using Streamlit and MySQL. This project enables users to explore flight data, check available flights between cities, and gain insights into air traffic trends through interactive visualizations.
## Features
- Check Flights:
  - Search for available flights between cities by selecting origin, destination, and flight date.
  - Retrieve details like departure time, arrival time, airline name, and route.
- Analytics Dashboard:
  - Airline Frequency: Analyze the number of flights operated by different airlines.
  - Busiest Airports: Identify the most active airports based on the number of arrivals and departures.
  - Daily Flight Trends: Visualize the total number of flights per day to track air traffic trends.
- Interactive Visualizations:
  - Pie chart for airline flight frequency.
  - Bar chart for busiest airports.
  - Line graph for daily flight trends.
## Tech Stack
- Frontend: Streamlit
- Backend: Python (MySQL Connector)
- Database: MySQL
- Data Visualization: Plotly, Pandas, NumPy
## Installation
### Prerequisites
Ensure you have the following installed:
- Python 3.x
- MySQL Database
- Required Python Libraries: streamlit, mysql-connector-python, pandas, numpy, plotly
Steps to Run the ProjectClone the repository:
- Clone the repository
- Navigate to the project folder
- Install dependencies
- Ensure your MySQL database is set up with the correct schema and flight data.
- Run the application
